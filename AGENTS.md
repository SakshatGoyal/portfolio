# Canonical portfolio repository

This repository is the main Sakshat Goyal portfolio website. Work on `main` and
read `PROJECT_GUIDE.md` before modifying the implementation.

Do not create a numbered successor or treat archived/source collections outside
this repository as the active site. Preserve finished content and interactions
unless the user explicitly requests a change. Run the validation commands in
`PROJECT_GUIDE.md`, and use the Codex built-in Browser for visual verification.
