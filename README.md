# Sakshat Goyal Portfolio

This is the canonical working website. The repository lives at
`/Users/sakshatgoyal/Documents/GitHub/portfolio/website` and publishes a static
Astro portfolio from `src/` using runtime assets in `public/`.

```sh
npm install
npm run dev
```

Use `npm run check` for repository contracts and Astro type checking. Use
`npm run build` for the full validation and production build.

The site contains the home page, About, and seven case studies under `/work/`.
See `PROJECT_GUIDE.md` before changing the implementation,
`CASE_STUDY_DESIGN_SYSTEM.md` for layout contracts, and
`CONTENT_PROVENANCE.md` for source relationships.
