# Figma content provenance

The case-study routes are direct transcriptions of the supplied Figma frames. Text, headings, emphasis, captions, metadata, and intentional source typos are preserved. Case-study imagery is downloaded from the nested nodes in the same file and stored locally; the website does not substitute stock or generated content.
