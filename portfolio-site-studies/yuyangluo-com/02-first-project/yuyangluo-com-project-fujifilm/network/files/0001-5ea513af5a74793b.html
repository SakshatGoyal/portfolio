Fujifilm Camera Remote
Your camera companion, simplified

Year
2019

Type
App concept

Agency
Self-initiated

Role
Designer

The Fujifilm Camera Remote is an application that can operate wireless-equipped digital cameras by remote control. It allows Fujifilm camera users to take photos wirelessly, view images & videos on their cameras, as well as transfer them to smartphones. This is a redesign concept project that tries to improve the user experience of the current application.
